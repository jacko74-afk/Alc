# 면세점 주류 비교

롯데·신라·신세계 인터넷 면세점 위스키 가격을 **성인인증가**와 **회원가(로그인+성인인증)** 두 줄로 비교합니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 생년월일 8자리(예: 19880101)를 입력하면 비교 화면이 열립니다.

관리자: http://localhost:3000/admin (기본 비밀번호 `admin`)

성인 확인 후 상단에 **면세점 회원 로그인** 메뉴가 있습니다. 각 면세점 로그인 창을 연 뒤 **완료**를 눌러야 회원가가 표시됩니다.

## 실제 가격 수집

관리자에서 **실제 가격 수집 (성인 + 회원)** 을 누르면 브라우저가 열립니다.

1. 성인인증만 한 상태로 성인인증가·원래가를 수집합니다.
2. 이어서 롯데·신라·신세계 로그인을 직접 하면 회원가를 수집합니다.

수집에는 수 분이 걸릴 수 있습니다. 결과는 비교 화면에 반영됩니다.

## 가격 기준

- 성인인증가: 로그인 없이 성인인증만 했을 때 보이는 판매가
- 회원가: 로그인 + 성인인증 후 기본 등급 회원 판매가
- 쿠폰·적립금·카드 할인은 포함하지 않음
- 초기 데이터는 샘플 가격입니다
